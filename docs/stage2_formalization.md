# Stage 2 — Formalization of the transducers

> Generated by `python -m Normalization.formalization`. Do not edit by hand.

## Conventions

- Transducers are deterministic finite-state transducers of Mealy type: the output is attached to each transition (ω: Q × Σ → Γ*).
- Every token is read followed by the end marker `⊣`. Reading it from the state of a complete variant goes to the accepting state and emits the canonical name (a single symbol of Γ). Every other transition outputs ε.
- Letters are accepted in lower and upper case (Σ contains both). The tables merge the two cases into one row (`r|R`).
- A token is **accepted** (normalized) only if the machine ends in F; otherwise it is rejected and reported as unrecognized.
- `␣` stands for the space character.

## Union transducer used by the pipeline

It recognizes every variant of every qualification through a shared prefix tree, so the whole catalog is normalized with one machine. Its full table is large; it is the union of the machines below, which are listed in full.
